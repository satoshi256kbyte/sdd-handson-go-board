# GoBoard

言葉による指示だけで、ブラウザで動くボードゲームを作るハンズオン用リポジトリです。
ゲーム本体は単一の `index.html` に HTML + CSS + JavaScript をインラインで実装しており、
外部ライブラリや CDN は使いません。

## ゲームの起動方法

`index.html` をブラウザで開くだけで起動します。ビルドやサーバーは不要です。

```sh
open index.html
```

上記が使えない環境では、`index.html` をブラウザのウィンドウにドラッグ&ドロップするか、
ファイルパスを直接ブラウザのアドレスバーに入力してください。

ページ読み込み時に、ビジネスロジックの自動テストが実行されます。
結果はブラウザの開発者ツールのコンソール（`console.log`）に出力されます。

## ディレクトリ構成

```text
.
├── index.html                 # ゲーム本体（HTML/CSS/JS を1ファイルに集約）
├── README.md
├── .kiro/
│   ├── specs/goboard/          # 仕様（要件・設計・タスク）
│   │   ├── requirements.md
│   │   ├── design.md
│   │   └── tasks.md
│   └── steering/               # プロジェクト全体の方針
│       └── product-overview.md
└── docs/                       # ハンズオン資料・解説・プロンプト例
```
